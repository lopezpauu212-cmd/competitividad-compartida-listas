# Competitividad Compartida - Turismo Sostenible en Cundinamarca

Prototipo de lista doblemente enlazada, desarrollado para la asignatura
de Estructuras de Información - Universidad de Cundinamarca.

## Integrantes
- Juana Sofia Corredor Herrera
- Maria Paula Quevedo Lopez

## Descripción
Este prototipo implementa una lista doblemente enlazada donde cada nodo
almacena un objeto `RutaTuristica` en lugar de un número. La entidad
`RutaTuristica` fue tomada del modelo entidad-relación del proyecto de
turismo sostenible en Cundinamarca (código, nombre, enfoque, duración).

## Métodos implementados
- `insertar(dato)`: inserta un nuevo nodo al final de la lista, recibiendo
  un objeto `RutaTuristica`.
- `mostrar()`: recorre la lista desde la cabeza y muestra cada ruta
  turística registrada.
